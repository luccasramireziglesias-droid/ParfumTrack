Vulnerabilidades resueltas

V-01

Bypass de activación por consola

✓ Resuelto ERA: Crítico
Antes window._activationVerified = true en DevTools activaba la app sin licencia. Variable accesible globalmente.
Después Estado movido a closure IIFE privado (_sec). No existe ninguna propiedad en window que controle la activación. 
// ANTES (explotable):
var _activationVerified = false;
function isActivated() { return window._activationVerified === true; }
// → en consola: window._activationVerified = true  ← app desbloqueada

// DESPUÉS (seguro):
const _sec = (() => {
  let _a = false;
  return {
    activate(v)   { _a = !!v; },
    isActivated() { return _a; },
  };
})();
function isActivated() { return _sec.isActivated(); }
// → en consola: _sec es undefined; no hay forma de llegar a _a
OWASP A07 — Identification Failures CWE-284 index.html:11876
V-02

Reinicio de trial vía localStorage / IndexedDB

✓ Resuelto ERA: Crítico

V-04

PIN salt hardcodeado y predecible

✓ Resuelto ERA: Alto
Antes Salt fijo "pt_salt_2026_" para todos los usuarios → rainbow tables pre-computables para PINs de 4-6 dígitos.
Después _ensurePinSalt() genera 16 bytes aleatorios en el primer uso, almacenados en pt_pin_salt. Cada usuario tiene un salt único. Backward-compatible vía fallback. 
function _ensurePinSalt() {
  if (!localStorage.getItem(PIN_SALT_KEY)) {
    const arr = new Uint8Array(16);
    crypto.getRandomValues(arr);
    localStorage.setItem(PIN_SALT_KEY,
      Array.from(arr).map(b => b.toString(16).padStart(2, '0')).join(''));
  }
}

R-01

Residual Alto

Una licencia activada puede ser copiada a otro dispositivo. Mitigación actual: maxUses limita la cantidad de activaciones. El contador se actualiza en cada validación. Solución completa requeriría heartbeat server-side + device binding (implica sesiones backend, fuera del alcance actual).

R-02

Trial anchor eludible con VPN + nuevo dispositivo

Medio Parcialmente mitigado

El anclaje por IP hash puede ser evadido con VPN + borrar storage. El anclaje por deviceId hash persiste mientras no se reinstale. En la práctica, el esfuerzo supera el valor del trial gratuito para la mayoría de usuarios.

Riesgo de explotación: Bajo/Medio Costo de evasión: Alto para el usuario
R-03

Datos en IndexedDB modificables

Residual Medio

Los datos de ventas/inventario están en IndexedDB, que puede ser editado con DevTools. Esto no afecta la seguridad de la licencia pero podría usarse para manipular reportes. Solución: Sync a backend (R2 backup ya implementado — pendiente activación del bucket).

Inherente a PWA offline-first Resolvible con R2 backup
