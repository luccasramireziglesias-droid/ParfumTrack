# Assets Gráficos — Play Store

## 1. Ícono de la app (obligatorio)

| Campo | Requisito |
|-------|-----------|
| **Tamaño** | 512 x 512 px |
| **Formato** | PNG 32-bit (con alfa) |
| **Archivo fuente** | `icon-512.png` (ya existe en la raíz del proyecto) |
| **Fondo** | Oscuro (#0f0f1a) |
| **Diseño** | Gota dorada — logo actual de Parfum Track |
| **Notas** | No agregar borde, sombra ni badge. Google Play le aplica la máscara automáticamente (esquinas redondeadas). |

**Estado: LISTO** — usar `/icon-512.png` tal cual.

---

## 2. Feature Graphic (obligatorio)

| Campo | Requisito |
|-------|-----------|
| **Tamaño** | 1024 x 500 px |
| **Formato** | JPG o PNG 24-bit (sin alfa) |
| **Nombre archivo** | `feature-graphic.png` |

**Diseño propuesto:**
- Fondo: degradado oscuro (#0f0f1a → #1a1a2e)
- Izquierda: texto "Parfum Track" en Cormorant Garamond bold, gold (#c9a84c → #e8c97e)
- Subtítulo: "Organizá tu negocio de perfumes" en DM Sans, cream (#f0ece4)
- Derecha: mockup de celular con screenshot del Dashboard
- Logo gota dorada pequeño arriba a la izquierda
- Sin texto chico ni CTA — Google lo muestra muy reducido

**Estado: POR CREAR**

| **Mínimo** | 2 screenshots |
| **Máximo** | 8 screenshots |
| **Nombres** | `screenshot-01.png` a `screenshot-08.png` |
