Arquitectura Técnica
Código, escalabilidad, seguridad, deuda técnica
6.5
/ 10
🚨
Problema #1 en tecnología: index.html tiene 7.009 líneas — HTML, CSS (2000+ líneas), JavaScript (4000+ líneas) y lógica de negocio todo en un único archivo. Esto es la mayor deuda técnica del proyecto. No es insostenible hoy, pero es el techo de crecimiento.
✅ Fortalezas técnicas
🌐
Cloudflare Pages

Hosting gratuito, CDN global, edge functions — infraestructura enterprise sin costo

🔐
HMAC-SHA256 para licencias

Token criptográfico server-side — no se puede falsificar en cliente

⏱️
Rate limiting via KV

10 req/hr por IP, 4 backups/día por código — protección real

🕵️
Constant-time comparison

timingSafeEqual() previene timing attacks en verificación de tokens

📱
PWA completa

Service Worker, manifest, offline-first, instalable en iOS/Android

🌙
Auto dark/light mode

Detecta prefers-color-scheme + listener para cambios en tiempo real

🔒
PIN con lockout en memoria

_failsMem persiste aunque borren localStorage en la misma sesión

❌ Debilidades técnicas
📄
Monolito de 7.009 líneas

Imposible hacer code splitting, tree shaking, o testing unitario

🗄️
KV namespace sin configurar

wrangler.jsonc tiene "REEMPLAZAR_CON_ID_REAL" — el rate limiting no funciona en producción

💾
IndexedDB sin schema versioning

Migraciones de datos futuras van a ser dolorosas

🧪
Zero tests

Sin unit tests, sin integration tests, sin E2E. Un bug puede romper todo silenciosamente

🔑
LICENSE_SERVER_SECRET no documentado

Si se pierde la variable de entorno, todas las licencias quedan inválidas

📦
app.js (218 KB) sin lazy loading

Se carga completo al inicio aunque no todo se usa

🌍
Sin i18n

Hardcodeado en español — expansión internacional requiere reescritura
